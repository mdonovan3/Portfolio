How It Works — A Concrete Walkthrough

Example domain: Geospiza fortis (medium ground finch), Daphne Major, Galápagos  ·  Transition: 1976 → 1977 (drought selection event)

This document walks through one complete inference cycle — from raw population measurements in the database to a stored, queryable causal belief — using the 1976→1977 Galápagos finch drought as the concrete example. This is the most documented natural selection event in the literature: a severe drought in 1977 caused the finch population to crash from ~1,240 to ~180, and the survivors had measurably deeper beaks, having cracked harder seeds when soft ones disappeared.

Three grammars evaluate the same transition simultaneously. Their results are stored separately — not merged, not averaged. A researcher can then query which grammar converged on the documented outcome, and what happens when a rule is removed.

STEP 1 Raw Data — What's in the Database

Each year's population measurements are stored as a snapshot — a row in Postgres with a JSONB features column. Two snapshots define a transition: the state before and the state after.

Snapshot A — year 1976 (pre-drought baseline)

{
  "year": 1976,
  "population": {
    "size": 1240,
    "survival_rate": 0.84
  },
  "morphology": {
    "mean_beak_depth_mm": 9.42,
    "mean_beak_length_mm": 9.80,
    "mean_body_mass_g": 15.6
  },
  "environment": {
    "annual_rainfall_mm": 130,
    "seed_hardness_index": 0.40,
    "seed_abundance_index": 0.74
  },
  "biotic": {
    "competitor_g_magnirostris": false
  }
}

Snapshot B — year 1977 (drought survivors)

{
  "year": 1977,
  "population": {
    "size": 180,          // crashed from 1240
    "survival_rate": 0.15   // 85% mortality
  },
  "morphology": {
    "mean_beak_depth_mm": 9.84,   // +0.42mm in survivors
    "mean_beak_length_mm": 10.12,
    "mean_body_mass_g": 16.2
  },
  "environment": {
    "annual_rainfall_mm": 24,        // 130mm normal → 24mm drought
    "seed_hardness_index": 0.91,    // soft seeds gone
    "seed_abundance_index": 0.18    // very scarce
  },
  "biotic": {
    "competitor_g_magnirostris": false
  }
}

The transition object links these two snapshots and will hold the inference results once the grammar runs. The delta values (change between A and B) are computed by the feature extractor: beak depth Δ = +0.42mm, survival rate = 0.15, rainfall dropped by 81%.

STEP 2 Predicate Registry — Mapping Columns to Named Atoms

Grammar rules don't reference column names directly. They reference named predicates. The predicate registry is the typed contract that maps raw column values to boolean atoms the grammar can reason over.

This indirection matters: if a column gets renamed or a threshold is recalibrated, you update the registry — not the rules. The grammar stays stable; the measurement layer changes beneath it.

seed_hardness_low environment.seed_hardness_index < 0.30 snapshot B
seed_scarcity environment.seed_abundance_index < 0.40 snapshot B

competitor_present biotic.competitor_g_magnirostris == true snapshot B

The predicate registry is also a validation contract. Before a grammar runs, the system checks that every predicate it references exists in the registry. A rule that references an undefined predicate fails at load time, not silently at inference time. This prevents grammars from compiling against features the feature extractor doesn't actually produce.
STEP 3 Evidence Atoms — What the Grammar Receives

The feature extractor reads the two snapshots, evaluates every predicate definition against the actual column values, and produces a set of boolean facts. This is what gets handed to ProbLog.

Evidence atoms for the 1976→1977 transition:

% True atoms (predicate evaluated to true given column values)
drought.                    % 24mm < 60mm threshold ✓
severe_drought.             % 24mm < 40mm threshold ✓
seed_hardness_high.         % 0.91 > 0.65 threshold ✓
seed_scarcity.              % 0.18 < 0.40 threshold ✓
population_bottleneck.      % survival_rate 0.15 < 0.35 ✓
beak_depth_increased.       % delta +0.42mm > 0.15 ✓

% False atoms (predicate did not fire)
el_nino :- fail.            % 24mm is not > 500mm
seed_hardness_low :- fail.  % 0.91 is not < 0.30
competitor_present :- fail. % G. magnirostris not on island yet
immigration_detected :- fail.
This atom set is what actually crosses the boundary into the inference engine. The grammar never sees column names, raw numbers, or JSONB paths — only named facts. This is the predicate registry contract in action.
STEP 4 Grammar Rules — Horn Clauses That Fire on Atoms

Grammar rules are probabilistic Horn clauses: if all conditions in the body are true, assign this probability to this causal conclusion. The YAML format compiles directly to ProbLog syntax.

YAML (what a domain expert authors):

- id: drought_selects_large_beak
  conclusion: directional_selection_larger_beak
  probability: 0.88
  all_of:
    - drought
    - seed_hardness_high
    - seed_scarcity
    - population_bottleneck

- id: severe_drought_amplifies
  conclusion: directional_selection_larger_beak
  probability: 0.92
  all_of:
    - severe_drought
    - seed_hardness_high
    - population_bottleneck

- id: el_nino_selects_small_beak
  conclusion: directional_selection_smaller_beak
  probability: 0.82
  all_of:
    - el_nino
    - seed_hardness_low

- id: character_displacement_selection
  conclusion: directional_selection_smaller_beak
  probability: 0.78
  all_of:
    - competitor_present
    - large_seed_niche_blocked

Compiled ProbLog (what the inference engine executes):

0.88::directional_selection_larger_beak :-
    drought, seed_hardness_high, seed_scarcity, population_bottleneck.

0.92::directional_selection_larger_beak :-
    severe_drought, seed_hardness_high, population_bottleneck.

0.82::directional_selection_smaller_beak :-
    el_nino, seed_hardness_low.

0.78::directional_selection_smaller_beak :-
    competitor_present, large_seed_niche_blocked.

Against the 1976→1977 atom set: drought, severe_drought, seed_hardness_high, seed_scarcity, and population_bottleneck are all true. The first two rules both have bodies that are fully satisfied. ProbLog combines them — the combined probability of directional_selection_larger_beak is higher than either rule alone. The el_niño and character displacement rules have false atoms in their bodies and do not fire.

STEP 5 Inference Result — The cause_distribution

ProbLog returns a probability for each possible conclusion. The feature extractor wraps this into the cause_distribution JSONB field and writes it to the transition_inferences table — one row per (transition, grammar).

transition_inferences row — grammar: selection_primary v1.0 
{
  "cause_distribution": {
    "directional_selection_larger_beak": 0.97,
    "stabilizing_selection":             0.02,
    "relaxed_selection":                 0.01,
    "directional_selection_smaller_beak": 0.00,
    "genetic_drift":                     0.00
  },
  "confidence": 0.94,
  "rule_trace": [
    { "rule": "drought_selects_large_beak",   "fired": true,  "weight": 0.88 },
    { "rule": "severe_drought_amplifies",      "fired": true,  "weight": 0.92 },
    { "rule": "el_nino_selects_small_beak",    "fired": false, "reason": "el_nino=false" },
    { "rule": "character_displacement_selection", "fired": false, "reason": "competitor_present=false" }
  ],
  "grammar_id": "selection_primary",
  "grammar_version": "1.0",
  "dataset_version": "1.0"
}

The rule_trace is the provenance record: which rules fired, which didn't, and why. A researcher can query this to understand not just what the system concluded but how it got there — and which rules were decisive.

STEP 6 Three Grammars — Same Transition, Different Posteriors

All three grammars evaluate the 1976→1977 transition simultaneously. Each produces its own row in transition_inferences. They are not merged or averaged.

selection_primary

v1.0

Theory: directional natural selection is primary

directional_selection_large: 0.97
stabilizing: 0.02
drift: 0.00

✓ Converges on documented outcome

drift_primary

v1.0

Theory: stochastic drift through bottlenecks is primary

genetic_drift: 0.75
directional_selection_large: 0.45
smaller_beak: 0.00

△ Drift fires (bottleneck is real) but misses primary cause

introgression_primary

v1.0

Theory: gene flow and competition are primary

within_population_process: 0.65
introgression: 0.00
displacement: 0.00

△ No immigration signal — defers to within-pop process, low confidence

This is the core epistemic value. The system doesn't force a single answer. It stores all three posteriors. A researcher can query: "across all 26 transitions, which grammar had higher confidence on transitions with documented ground truth?" That's calibration — and it's a query, not a re-run.
STEP 7 Theory Perturbation — Remove One Rule, See What Breaks

Create selection_primary v2.0 by removing the drought_selects_large_beak rule. Rerun the same transition. The transition_inferences table now holds a new row tagged to v2.0 alongside the original v1.0 row. Both are stored; neither overwrites the other.

selection_primary v2.0 — drought rule removed 
{
  "cause_distribution": {
    "directional_selection_larger_beak": 0.52,   ← dropped from 0.97
    "stabilizing_selection":             0.28,   ← rose
    "relaxed_selection":                 0.14,   ← rose
    "genetic_drift":                     0.06    ← rose
  },
  "confidence": 0.41,                            ← dropped from 0.94
  "rule_trace": [
    { "rule": "drought_selects_large_beak", "fired": false, "reason": "RULE REMOVED" },
    { "rule": "severe_drought_amplifies",   "fired": true,  "weight": 0.92 }
  ]
}

The posterior weakens dramatically when the primary drought rule is absent. severe_drought_amplifies still fires (it's a separate rule with overlapping but not identical conditions), so the conclusion doesn't collapse entirely — but confidence drops from 0.94 to 0.41.

This is structural sensitivity analysis: not "what if the weight were 0.80 instead of 0.88" but "what if this causal pathway didn't exist in the theory at all?" The answer is quantified and stored. The comparison between v1.0 and v2.0 is now a single SQL query. 

-- Query: how much did removing the drought rule change the posterior?
SELECT
    v1.cause_distribution->>'directional_selection_larger_beak' AS v1_prob,
    v2.cause_distribution->>'directional_selection_larger_beak' AS v2_prob,
    v1.confidence - v2.confidence                                       AS confidence_drop
FROM transition_inferences v1
JOIN transition_inferences v2 ON v1.transition_id = v2.transition_id
WHERE v1.grammar_version = '1.0'
  AND v2.grammar_version = '2.0'
  AND v1.transition_id = '1976_1977';
STEP 8 What Gets Stored — The Full transition_inferences Row

The defining feature, made concrete: a researcher can now ask — across all 26 annual transitions in the dataset, across all three grammars, across all grammar versions — any of these questions without re-running any analysis:
  • Which grammar had the highest mean confidence on transitions with known ground truth?
  • Which transitions have the highest disagreement between selection_primary and drift_primary?
  • How did removing the drought rule change the posterior on every transition in the dataset?
  • What was believed about the 1983 transition before and after we calibrated the seed hardness threshold?
